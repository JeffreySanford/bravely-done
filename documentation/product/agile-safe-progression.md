# Progressive Agile and SAFe Structure

Agile and SAFe concepts are implementation tools, not the default player vocabulary.

## Progressive disclosure

- Task → Quest
- Subtask → Encounter
- Project → Questline
- Milestone → Landmark
- Sprint → Expedition or Adventure Sprint
- Initiative → Campaign
- Team → Party
- Organization → Guild

When professional mode is enabled, the same objects may expose standard terminology, reporting, dependencies, risks, and governance.

## Complexity trigger

A simple quest stays simple. The application may suggest a questline when work has multiple outcomes, dependencies, owners, risks, or spans several sessions.

## SAFe-inspired mapping

- Portfolio epic → Realm objective
- Capability → Campaign capability
- Feature → Major quest
- Story → Quest
- Task → Encounter
- Program Increment → Season

This mapping is optional and must never contaminate the consumer experience with administrative burden.
