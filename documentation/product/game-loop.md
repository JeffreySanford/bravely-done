# Core Game Loop

## Primary loop

1. Return to Base Camp.
2. Receive useful context from the companion.
3. Choose or create a quest.
4. Select a small first encounter or Adventure Sprint.
5. Perform the real-world work.
6. Resolve honestly: complete, continue, split, retreat, or request help.
7. Receive rewards appropriate to effort and outcome.
8. Apply visible progress to camp, companion, inventory, and campaign.

## Design rule

The reward must follow useful action. Opening the application may grant a welcome moment, but substantial rewards require starting, focusing, planning, helping, or completing.

## Resolution states

- **Complete:** objective achieved.
- **Continue:** meaningful progress made; another encounter remains.
- **Split:** task was larger than expected and becomes a questline.
- **Retreat:** stop safely, preserve learning, and create a better next step.
- **Call the party:** ask a trusted person or team for help.

No resolution should shame the player.

## First playable loop

The initial vertical slice uses one quest, one sprint, deterministic rewards, and one persistent Base Camp construction upgrade.
