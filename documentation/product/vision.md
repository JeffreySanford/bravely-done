# Product Vision

Bravely Done turns real-life progress into a welcoming adventure. It is for people who understand what they should do but need help starting, sustaining attention, recovering from interruption, or coordinating complicated work.

## Problem

Most task applications make the user repeatedly face obligation, backlog, and failure. Gamified applications often add points without changing that emotional experience. Enterprise planning tools add useful structure but can overwhelm individuals.

## Answer

Bravely Done presents a living game world in which useful actions create meaningful consequences. Productivity data is captured underneath play rather than becoming the main emotional surface.

## North-star experience

> Return to camp, choose a quest, take one brave step, receive a satisfying response, and see the world become better because real work was completed.

Companion AI ("Ember" and its roster of avatars — see [AI companion](ai-companion.md)) is a central,
motivating part of that experience, not a bolted-on feature. It coaches, and — within a confidence-based
trust boundary — can act on the player's behalf. The *core* quest/sprint loop still functions with
Ember disabled, but the intended experience assumes Ember is present.

## Audiences

1. Individuals completing personal, health, learning, household, or professional tasks.
2. Freelancers tracking bounties, time, and earnings.
3. Friends and small parties pursuing shared goals.
4. Teams coordinating campaigns with optional professional and SAFe views.

## Non-goals for the first release

- A full MMO
- A complete enterprise portfolio suite
- A social network built around public performance
- AI-dependent basic functionality
- Punitive streaks or manipulative variable-reward monetization
