# Quality Gates

Bravely Done protects both engineering quality and the game-first product promise.

- [FUN factor gate](fun-factor-gate.md): verifies that player-facing work improves motivation, delight, clarity, or meaningful game consequence.
- [Testing gate](testing-gate.md): defines test layers and 98% coverage governance.
- [Testing exceptions](testing-exceptions.md): records justified gaps, risks, and removal criteria.

A technically correct feature that makes Bravely Done feel like administrative software has not passed quality review.
