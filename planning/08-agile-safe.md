# Plan 08: Agile and SAFe

See [Agile/SAFe progression](../documentation/product/agile-safe-progression.md) for the product
decisions this plan implements. Dual-labeled vocabulary (game term + real term shown together) is the
**default presentation**, not an optional toggle — and the role/skill-tree system is core scope, not
deferred "complex work" polish.

## Vocabulary and structure

- [ ] Add questlines, milestones, dependencies, and risks.
- [ ] Add campaign planning and team contribution views.
- [ ] Show dual-labeled vocabulary (game term + real term) by default throughout.
- [ ] Map Epic/Capability/Feature/Story/Task to game vocabulary.
- [ ] Add season/program-increment planning only for qualified complexity.
- [ ] Add reporting without exposing private personal quests.

## Role/skill-tree system

- [ ] Build the role/class model: Facilitator, Product lead, Adventurer, Scout, etc. — each with an
      independent level and a full branching skill tree (D&D-class-style mechanics; visual style stays
      sci-fi/cyber, not fantasy).
- [ ] Support switching roles at will.
- [ ] Keep the role system domain-neutral (not software-development-locked).
- [ ] Couple every functional skill-tree unlock to a visible game-layer effect (animation/buff/title).
- [ ] Support real-invited or matchmade party formation.
- [ ] Support personal backlog + shared team backlog simultaneously.

## Portfolio/community tier

- [ ] Build the persistent cross-team dependency board.
- [ ] Build scheduled, time-boxed live ceremony events (PI-Planning-style), Ember-facilitated.
- [ ] Implement portfolio-tier roles (Lean Portfolio Management, RTE-equivalent) as level-gated **and**
      community-elected — not a pure XP grind.

## Validation

- [ ] Run usability test proving simple quests remain simple even with dual-labeled vocabulary present.
